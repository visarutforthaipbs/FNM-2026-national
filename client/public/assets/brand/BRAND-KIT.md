# โรงงานใกล้ฉัน — Website brand kit

แนวคิด: **Civic field guide** — เครื่องมือข้อมูลสาธารณะที่ดูน่าเชื่อถือ ใช้ง่าย และไม่สร้างความตื่นตระหนกเกินข้อมูลจริง

## Core assets

- `brand-symbol.svg` — app icon, favicon, compact navbar, map attribution
- `brand-lockup.svg` — full horizontal signature for partners, about pages, and reports
- `og-cover.svg` / `og-cover.png` — social sharing and link previews (1200 × 630)
- `brand-pattern.svg` — low-attention background for section headers and campaign cards
- `empty-search.svg` — empty search/filter state
- `map-home-marker.svg` — user/home location marker
- `map-factory-marker.svg` — reusable safe-state factory marker; runtime color changes to red for high-risk factories

## Brand language

- Public Service Blue `#0B3558` — trust, structure, navigation
- Locator Orange `#F05223` — current location and primary action only
- Contour Blue `#8FB9C9` — geographic context and secondary graphics
- Paper `#F7FAFB` — quiet information surface
- Alert Crimson `#EF4444` — evidence-backed high risk only; never as decoration

Use the orange locator as the single visual signal in a composition. Risk colors belong to data, not branding. Keep at least one symbol-height of clear space around the full lockup and never place it on a visually busy map without a solid surface.
